# Graduation-Project_RPG_sanxiao

毕业设计 · 三消 RPG

## 打开工程

使用 Cocos Creator **3.8.8**。在 Cocos Dashboard 的项目列表中选择「导入」，选中本仓库下的 **毕业设计demo** 文件夹（包含 `package.json`），然后打开工程。

- `毕业设计demo/assets/` 存放脚本、美术与场景。移动资源时一并保留对应的 `.meta` 文件。
- `毕业设计demo/settings/` 存放共享项目设置。
- `library/`、`temp/` 和 `profiles/` 由编辑器在本地生成。

当前工程包含项目配置和初始资源目录。
